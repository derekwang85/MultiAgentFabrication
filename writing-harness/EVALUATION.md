# 进化评估规约（EVALUATION.md）

本规约是《驾驭 AI · AI Harness Engineering》系列写作流程中，与 `writing-harness/GATES.md` 并行的另一条纪律。它回答一个门禁回答不了的问题：**门禁保证"这篇文章没坏"，进化评估保证"这篇文章变得更好"。**

## 一、门禁与进化评估的分工

| 维度 | 门禁（GATES.md） | 进化评估（本规约） |
|------|------------------|--------------------|
| 对象 | 单篇文章是否达标 | 整条系列是否在变好 |
| 判据 | 固定检查项（风格/结构/事实/链接/评审） | 无固定指标，只对照"前序均值"和"突破维度" |
| 自动化 | `writing-gates.py`（脚本可执行） | `evaluate.py`（脚本可执行） |
| 态度 | 守下限：不合格就拦住 | 拉上限：不破前均就不算进步 |

一句话：**门禁是底线，进化是天花板。** 两者缺一不可——只守门禁，系列会停在"都合格但都平庸"；只讲进化，单篇可能连门禁都过不去。

## 二、核心规则

1. **逐篇评分**：每篇文章（含序章，不含附录/修订记录）在完成后评一个综合分，10 分制，可带一位小数。
2. **前序为基准**：新文章的合格线 = 前序所有文章分数的算术平均，且要求**严格大于**（不是大于等于）。
3. **每次重写重新计**：不论首稿还是重写升级，一旦落稿评分，就把新分数写回，并重算滚动平均，作为下一篇的基准。
4. **突破是硬要求**：每篇至少落实一个"突破维度"的标注（见第四节），并在正文可见地体现出来。没有突破维度标注的文章，评估不通过。
5. **评分在门禁之后**：文章先过 `writing-gates.py` 的 G1-G5，再评综合分。门禁不过，不进评分环节。

## 三、数据契约

所有分数与元信息落在单一数据源：

```
writing-harness/evaluation-scoreboard.json
```

结构约定：

```json
{
  "schema_version": "1.0",
  "updated": "YYYY-MM-DD",
  "articles": [
    {
      "key": "05-gates",
      "title": "第 5 篇 门禁层",
      "file": "articles/04-gates.md",
      "score": 8.6,
      "status": "样稿待审",
      "date": "2026-08-29",
      "score_history": [["8.4", "2026-08-26", "首稿"], ["8.6", "2026-08-29", "重写升级"]],
      "breakthrough": "戴明质量管理引用（新名言）",
      "note": "重写升级版：补 derekinside 注脚、戴明开篇、评审留痕"
    }
  ]
}
```

字段约定：`key` 为固定唯一篇目标识；`file` 为相对 `articles/` 的路径；`score` 为此前评定的当前分；`score_history` 记录每次首稿/重写的评分轨迹（首稿无此字段）；`breakthrough` 为该篇主要突破点的一句话描述；`note` 为评分理由与扣分点说明。

## 四、突破维度与参考来源

每篇至少落实一个突破。三个可选的突破轴：

- **遣词造句**：金句、比喻、句式有明显的可记忆点，超出前序平均水平。
- **经典案例**：引入一个前序未用过的、有真实出处的行业/历史/技术案例，并落进论证。
- **名言名句引用**：引用一位前序未引用过的人物名言，且要与观点咬合，不止于装饰。

判定参考的可信来源（新引用应尽量来自这些方向中的一个，且前序未用过）：

- 管理思想：德鲁克（前序已用"效率 vs 效能""被衡量的才能被管理"）、戴明（已用"质量不是检查出来的"）
- 军事战略：克劳塞维茨《战争论》（第 7 篇已用）
- 工业史：泰勒/福特流水线（第 4 篇已用）
- 科技史/工程隐喻：航空双引擎、断路器（第 6 篇已用）、建筑蓝图（第 1 篇已用）

后到的篇目应避开已用出处，向未开采的方向（如管理组织学、系统论、哲人名言、开源历史）寻找新引用——这正是"不断突破"落地的位置。

## 五、操作时序

一篇新文章（或一次重写）要走完下面的顺序：

1. **动手前**：执行 `python evaluate.py --next`，读当前基准线，确定本文目标分（须 > 基准，建议留 0.2 余量）与计划落实的突破维度。
2. **写作**：带着"超过前均"与"双重复合"（内容质量、行文表达）的目标动笔，将突破维度落在正文可见处。
3. **过门禁**：运行 `python writing-gates.py articles/<文件>.md`，确认 G1-G5 全部 PASS。
4. **自评/评审**：按 `GATES.md` 补"附：门禁评审记录"块，rubric 自评 + 独立评审结论。
5. **录入**：运行 `python evaluate.py --record articles/<文件>.md --score <分> --breakthrough <突破描述> --note <注>` 或 `--update` 更新既有篇目。
6. **同步**：把新分数回写到 `docs/article-evaluation-system.md` 的人类可读评分表，保持两处一致。

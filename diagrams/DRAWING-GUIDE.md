# diagrams 绘制规约（Drawing Guide)

> 本文件是 `diagrams/` 所有 drawio 图的**坐标与排版铁律**，从 fig-00-5 手工精调中提炼。
> 生成管线只保证几何正确（R1-R3），**不保证视觉对齐**；对齐是数据源（`data_src.py`）写作时的责任。
> 任何一张新图，动笔前先过一遍本规约。

## 0. 三个几何门禁（已有，覆盖到这里）

- R1 边不穿节点（`zone` 例外）
- R2 正交边不共线重叠（共享端点除外）
- R3 不越界不悬空（折点/标签在画布内）

门禁机器可跑：`python diagrams/arch_qa.py <fig-id>`。

## 1. 上对齐（Top-Align）——同一语义行的块必须左缘共线

- 同一"行"（语义并列）的所有列块，**x 必须严格相等**。
- 典型坑：列头与第一行内容用了不同的 x（如列头 `320`、内容 `340`），肉眼看起来"头悬空"。
- 反例（fig-00-5 旧版）：`col_sub x=320` vs `s1 x=340` —— 左缘不共线，已修。
- 铁律：**列头、内容块、底部结论带，只要语义上属于同一列，x 就必须相同。**

## 2. 等宽列（Equal-Column），列内块宽度统一

- 同一列内，所有块的 **w（宽度）必须相等**，避免"宽窄参差、锯齿右缘"。
- 反例（fig-00-5 旧版）：列头 `w=470` vs 内容块 `w=430` —— 已统一为 `430`。
- 铁律：**列宽=全列块的共识宽度；任何一块想变窄，整列一起变。**

## 3. 健全中缝（Gutter）——连接线必须有专属垂直通道

- 两列之间、列内相邻块之间，必须留出**明确的空垂直中缝**，正交连线从这里走，不穿进内容区。
- 反例：把块铺满画布，边被迫从块内部或块与块的夹缝里挤过去。
- 铁律：**每列一个固定的中缝 x 坐标（列中心），列内所有上下级边都走它。**
  - fig-00-5：左列中缝 `x=555`（=340+430/2），右列中缝 `x=1040`（=850+430/2）。

## 4. 收窄聚焦带（Focused Band）——上下两端的"帽子/结论"要相对内部收窄并居中

- 最顶的解释区（`root`）和最底的结论区（`verdict`）不要横跨整幅画布，而是**相对两列整体居中收窄**，让视线聚焦到核心句，也让上下形成对称的"帽-带"骨架。
- 反例（fig-00-5 旧版）：`root/verdict w=1280`、整宽——边缘大块留白被"砍"，图显得散。
- 已修：`root/verdict w=940, x=340`，与两列的外边界（左列 x=340、右列右缘 850+430=1280）形成对称内嵌。
- 铁律：**帽带宽度 ≈ 列起点到末端列右缘的 span；位置 = 相对整体水平居中。**

## 5. 对称边距（Symmetry）——左右两列到画布边缘留白一致

- 左列起点到画布左缘、右列右缘到画布右缘，留白应大致相等。
- fig-00-5：左列 `x=340`，右列右缘 `=850+430=1280`；画布 `W=1400` → 左边距 340，右边距 120。理想时两边都约等于(1400-(850+430-340))/2=(1400-940)/2=230，即两列整体相对画布居中。
- 铁律：**两列整体相对画布水平居中；新图把 X-group 算好再排块，别随手定 x。**

## 6. 序号锚点（Numbered Anchor）

- 对比类图，每行用 `①…⑧` 等序号锚定"同一维度跨列对应"，序号必须成对且顺序一致（左列 i 对上右列 i）。
- 视觉上序号尽量逐行整齐推进，不要跳号。

## 7. 排版一致性（Typography）

- 标题行与注释行两级字号：主体 `fontSize` 一致（如 12.5/13），注释统一 `10px` + `#5b6475`。
- 中文注释不中英混排带割裂感的地方用全角空格/顿号统一，标点一致。

## 8. 抽象升维（Paradigm Abstraction）——图要画"结构"，不是复刻原文的另一种写法

- 复刻式画图 = 把原文图/表逐格换成色块，只换"表达方式"；升维式画图 = 先问"这一页想说哪一条结构"，再用**容器/分类**把散点收敛成一两个可读的抽象。
- fig-00-5a 示范：原文是"八维对照表"，本图不逐行再画八行，而是抽象出 **同心包裹**（同一单点判断器被两层容器依次包裹）。
- 判据：看完图能一句话说清"结构"，且这个结构不是源文章的目录重排。若图只是把 N 个事实改成 N 个框，等于没画。
- 升维工具：
  - **容器即分类**：用包围式 zone 表示"变的是什么"（外包手 → 分工组织），内层 core 表示"不变的是什么"（核心判断器）。
  - **质变分界标记**：变与不变的临界图层，用高亮（如 `hl`）标记，读者第一眼就盯住"关键一层在换什么"，而不是数层数。
- **读图法禁令**：**不要在图上写"读图法 / 应该怎么读 / 从内到外看 / 盯住某层"这类说明**。读图说明属于胶囊，不属于图画；写了只会让发表图显得像教学稿。改为「标题即结论」——把"本图看什么"直接锻进 `title`（洞察句）+ 每个 `zone` 标题（分类语义），读者只看图形+标题即可复述结构。
  - 反例（fig-00-5a 旧版）：底部结论带 `key` 写"读图法：从内到外=……"，已删除。
  - 改进：fig-00-5a 现在把结论锻进 zone 标题（不可判定域/可仲裁域），并设 `key` 只做词表或直接省略。
  - 铁律：**读图顺序/阅读提示一律不进图内文字；如需帮助读者，放正文或图注，不放图上。**
- 铁律：**动笔先写一两行"本图要表达的结构命题"；画出来的图必须让读者只靠图形+标题就能复述它。写不出来，就先别画。**

## 检查清单（新增/改图时逐条过）

- [ ] 同一语义行各列 x 相同（上对齐）
- [ ] 每列内 w 相同（等宽）
- [ ] 每列有专属垂直中缝，边全部走中缝
- [ ] root/verdict 相对整体居中收窄形成帽带
- [ ] 两列整体相对画布水平居中，两侧留白大致相等
- [ ] 序号跨列成对
- [ ] 字号/注释分级统一
- [ ] 图能一句话复述"结构命题"，且不是源文章的另一种写法（抽象升维）
- [ ] 变/不变的临界层有视觉分界（高亮/容器），读者一眼盯住"关键层在换什么"
- [ ] `python diagrams/arch_qa.py <fig-id>` 通过 R1-R3
- [ ] 图内无「读图法 / 阅读顺序」等读图提示文字；结论已锻进 title + zone 标题
- [ ] 边标签底框不落入任何流程框；`verify_labels.py` 输出 OK
- [ ] 无穷框实测（W/H 收紧到内容刚好放下），亮/暗双主题 + 印刷配色均正常
